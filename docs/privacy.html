Privacy Policy

Last updated: 2026-07-26

"Daily Life Videos" is a personal automation tool built and operated by a single individual developer. It generates short-form videos and uploads them to one YouTube channel owned by that same developer. It is not a public app, has no public sign-up, and no other person's account or data is ever involved.

What data this tool accesses

The tool uses the YouTube Data API v3 with the youtube.upload scope, authorized directly by the developer's own Google account, solely to upload video files the developer created to their own channel.

What data this tool does not do

  • It does not collect, process, or store personal data belonging to any other person.
  • It does not share, sell, or transfer any data to third parties.
  • It does not use any data for advertising or profiling.
  • It has no other users, so no other user's data ever exists within it.

Data storage

OAuth credentials are stored only as encrypted secrets within the developer's private automation infrastructure (GitHub Actions secrets), never committed to source control, and never accessible to anyone but the developer.

Contact

Questions about this policy can be raised as an issue on the project's GitHub repository.
